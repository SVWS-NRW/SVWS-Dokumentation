# WeNoM - Handbuch  für Lehrkräfte

::: tip Nutzen Sie den fertig aufsetzten Server
Hier finden Sie die Benutzerhandbücher für den WebNotenManager. Zum einen finden Lehrkräfte hier einen schnellen Einstiege zur Nutzung des WebNotenManagers im **Handbuch für Lehrkräfte**.
:::

Die Installation des WebNotenServers finden Sie weiter unten im Inhaltsverzeichnis unter **Installation des Servers**.

Um für Lehrkräfte Kennwörter neu zu setzen, Noteneintragungen zu ermöglichen und diese mit dem SVWS-Server zu synchronisieren, finden sich die hierzu erforderlichen Schritte im Bereich **Schulische Verwaltung des Servers**, so dass die hierzu in der Schule Beauftragten diese Vorgänge schnell beherrschen.
