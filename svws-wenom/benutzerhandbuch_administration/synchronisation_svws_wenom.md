# Synchronisation SVWS - WeNoM

Um die angepasste Konfiguration im Notenmodule für den externen WeNoM - Server bereitzustellen oder Änderungen bei den Benutzerberechtigungen auch für den externen WeNoM - Server bereitzustellen, ist es erforderlich, dass Sie eine Synchronisation zwischen dem internen SVWS-Server und dem externen WeNoM-Server aktiv durchführen.

Was dabei zu beachten ist und wann Sie Daten hochladen, herunterladen oder synchronisieren können / sollten, erfahren Sie in diesem Kapitel.
