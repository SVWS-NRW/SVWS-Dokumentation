# Erziehungsberechtige
In diesem Bereich werden Ihnen die Erziehungsberechtigten einer Schülerin beziehungsweise eines Schülers angezeigt und bearbeitet.

![Erziehungsberechtigte](./graphics/SVWS_schueler_erziehungsberechtigte.png "Tragen Sie hier die Erziehungsberechtigten ein.")

Hier sehen Sie beispielhaft eingetragene Erziehungsberechtigte sowie einen eigenen Eintrag zum Schüler Torsten Blaurock, der volljährig ist.

![Beispieltabelle aller Erziehungsberechtigten](./graphics/SVWS_schueler_erziehungsberechtigte_Tabelle.png "Hier sehen Sie ein Beispiel für den Eintrag von Erziehungsberechtigten.")

Über das **+** ganz rechts können Sie weitere Erziehungsberechtigte hinzufügen. Es erscheint ein Pop-up-Fenster:

![Pop-up-Fenster Erziehungsberechtigte hinzufügen](./graphics/SVWS_schueler_erziehungsberechtigte_hinzufuegen.png "Es wird ein Pop-up-Fenster aufgerufen, Erziehungsberechtigte hinzuzufügen.")

Wählen Sie die *Erzieherart* aus. Dazu können Sie unter den eingetragenen Erzieherarten per Auswahlmenü wählen.

![Auswahlfenster Erzieherart auswählen](./graphics/SVWS_schueler_erzieherart-auswahl.png "Es wird ein Auswahlenster aufgerufen, um die Erzieherart auszuwählen.")

Wählen Sie die gewünschte *Erzieherart*. Weitere Möglichkeiten können in der **App Schule** ➜ **Kataloge** ➜ **Erzieherarten** bearbeitet und bei Bedarf ergänzt werden.

Füllen Sie nach der Auswahl die restlichen Felder aus, wobei lediglich die Pflichtfelder *Rufname* und *Nachname* notwendig sind.

::: tip Weitere Informationen
Im Feld *Bemerkungen* können freie Informationen eingetragen werden. Hier könnte zum Beispiel ein Kontaktverbot eingetragen werden.
:::

Als nächstes ist zu markieren, ob diese Person ein automatisch generiertes Anschreiben erhalten soll (***Erhält Anschreiben***).

Weiterhin können Sie zu diesem Erzieher-Datensatz eine zweite Person angeben, indem Sie auf ***+2. Person*** klicken. Es öffnet sich ein weiteres Pop-up-Fenster:

![Pop-up-Fenster 2. Person eintragen](./graphics/SVWS_schueler_erziehungsberechtigte_hinzufuegen_2.person.png "Es wird ein Pop-up-Fenster aufgerufen, um eine 2. Person einzutragen.")

Auch hier sind der *Rufname* und *Nachname* Pflichtfelder, um die *2. Person speichern* zu können.

Klicken Sie auf den **Speichern**- beziehungsweise den **2. Person speichern**-Button, um den Datensatz anzulegen.

## Weitere Arten von Ansprechpartnern

Erfassen Sie weitere Ansprechpartnern wie zum Beispiel *Partner*, *Onkel* oder *Jugendamt* und *Tante*. Bei Personen, die nicht erziehungs- beziehungsweise sorgeberechtigt sind, ist in der Regel ***Erhält Anschreiben*** abgewählt.

::: tip
Der Eintrag ***Schüler ist volljährig*** ist dann einzutragen, wenn die Schülerin beziehungsweise der Schüler volljährig ist und demnach persönlich ein Anschreiben erhält. Wenn dieser Eintrag vorhanden ist, wird bei einem Reports an die Erziehungsberechtigten auch der Schüler automatisch adressiert.
:::
