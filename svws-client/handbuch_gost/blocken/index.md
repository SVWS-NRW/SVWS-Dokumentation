# V. Blocken

Das Berechnen einer Blockung ist ein komplexes Thema, das sehr ausführlich in den Artikel zur **App Oberstufe** ausgeführt und aktualisiert wird.

Eine nur auf Kernaspekte reduzierte Darstellung kann der zu erledigenden Aufgabe nicht gerecht werden. Daher werden an dieser Stelle im Inhaltsverzeichnis diese Artikel eingebunden und gelten somit als der nächste Teil dieses Handbuches.

:::tip Was ist eine Blockung?
In der Übersicht: Bei einer "Blockung" handelt es sich um eine Berechnung, wie viele Kurse mit ihren Kursarten eines Faches angeboten werden, welche Kurse davon parallel liegen und welche Schülerinnen und Schüler dem jeweiligen Kurs zugeordnet werden, damit alle Fachwahlen berücksichtigt sind, ohne dass es zu Kollisionen kommt.
:::

Bei der Berechnung einer Blockung können schon Fachlehrkräfte zugeordnet werden, dies muss jedoch noch nicht geschehen. Weiterhin können Sie viele **Regeln** definierten, etwa, welche Kurse parallel liegen sollen, welche auf keinen Fall, ob bestimmte Schüler in einen Kurs müssen und so weiter.

Nachdem eine Blockung erstellt wurde, wird diese den Leistungsdaten zugewiesen und alle geplanten Kurse werden automatisch angelegt.

Anschließend kann eine Blockung für externe Programme exportiert werden.

## APO GOSt 2026

Für das Abitur nach der APO GOSt 2026 mit dem Abitur ab 2030 ist besonderes Augenmerk auf die komplette Laufbahn von der EF bis zur Q-Phase zu richten. Das Ermöglichen der *Gleichwertigen Komplexen Leistungsnachweise (GKL)* erfordert mitunter schon zum Beginn der EF ein vorausschauendes Planen und Beraten.

Die GKL werden über die *Klausurplanung* in den Schülerlaufbahnen wählbar, so dass auch frühzeitig eine Klausurplanung anzulegen ist. Sollen GKL zum Beispiel in der Q2 möglich sein, ist schon vor Beginn einer neuen EF für diesen Lernabschnitt eine Klausurplanung zu hinterlegen.
