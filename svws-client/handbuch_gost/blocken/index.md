# V. Blocken

Das Berechnen einer Blockung ist ein komplexes Thema, das sehr ausführlich in den Artikel zur **App Oberstufe** ausgeführt und aktualisiert wird.

Eine übersichtsartige Darstellung kann der Aufgabe nicht gerecht werden. Daher werden an dieser Stelle im Inhaltsverzeichnis diese Artikel eingebunden und gelten somit als der nächste Teil dieses Handbuches.

Als kurze Einführung sei hier mitgeteilt: Bei einer "Blockung" handelt es sich um eine Berechnung, wie viele Kurse mit ihren Kursarten eines Faches angeboten werden, welche Kurse davon parallel liegen und welche Schülerinnen und Schüler dem jeweiligen Kurs zugeordnet werden, damit alle Fachwahlen berücksichtigt sind, ohne dass es zu Kollisionen kommt.

Bei der Berechnung einer Blockung können schon Fachlehrkräfte zugeordnet werden, dies muss jedoch noch nicht geschehen. Weiterhin können Sie viele Regeln definierten, etwa, welche Kurse parallel liegen sollen, welche auf keinen Fall, ob bestimmte Schüler in einen Kurs müssen und so weiter.

Nachdem eine Blockung erstellt wurde, wird diese den Leistungsdaten zugewiesen und alle geplanten Kurse werden automatisch angelegt.

Anschließend kann eine Blockung für externe Programme exportiert werden.
